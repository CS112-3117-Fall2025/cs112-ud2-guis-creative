## Project Description

This project is a **Workout Tracker GUI application** designed to help users track their workouts. Users can add cardio and strength workouts and view all workouts they have entered. This project demonstrates a basic GUI layout using Java Swing, with buttons and labels organized in a simple grid layout.

## Functional Feature

One feature of the program currently works:

- **Add Cardio Workout Button:** When the user clicks the **“Add Cardio Workout”** button, a message is printed to the console:  
Cardio workout added!

- This is meant to demonstrate the interaction between the GUI and program logic, it is the one functional feature within the GUI.

---

## Notes

- The GUI currently has three buttons:
1. Add Cardio Workout  
2. Add Strength Workout  
3. View All Workouts  

- Layout is implemented using **GridLayout**, and the window title is **Workout Tracker**.  
- Future improvements I could make could include storing workouts in a list, adding input fields for workout details, having a user sign in, displaying all workouts in the GUI, and implementing a way to exit the program without just clicking 'x'.
